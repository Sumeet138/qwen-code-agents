# before-you-build

Pre-build product risk review for founders, product teams, and AI-assisted builders before implementation starts.

## Components

### Skills

- **before-you-build**: See `skills/before-you-build/SKILL.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
