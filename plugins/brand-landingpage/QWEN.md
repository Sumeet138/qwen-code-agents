# brand-landingpage

Guides developers from brand discovery through iterative design to deployment-ready HTML via Stitch.

## Components

### Skills

- **brand-landingpage**: See `skills/brand-landingpage/SKILL.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
