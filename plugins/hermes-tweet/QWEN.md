# hermes-tweet

Hermes Agent plugin for public X/Twitter research and approval-gated private or state-changing operations through Hermes Tweet

## Components

### Skills

- **hermes-tweet**: See `skills/hermes-tweet/SKILL.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
