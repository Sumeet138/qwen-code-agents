# pptx-deck-creation

Create production-ready, editable PowerPoint decks through a spec-first, coordinate-explicit workflow with read-only reference analysis and quality gates.

## Components

### Agents

- **pptx-deck-creation-builder**: See `agents/pptx-deck-creation-builder.md`

### Skills

- **pptx-deck-context**: See `skills/pptx-deck-context/SKILL.md`
- **pptx-quality-gates**: See `skills/pptx-quality-gates/SKILL.md`
- **pptx-reference-deck-analysis**: See `skills/pptx-reference-deck-analysis/SKILL.md`
- **pptx-slide-specification**: See `skills/pptx-slide-specification/SKILL.md`
- **pptx-visual-assets**: See `skills/pptx-visual-assets/SKILL.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
