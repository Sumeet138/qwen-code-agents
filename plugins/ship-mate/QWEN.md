# ship-mate

Your AI development teammate. Turns a story file into a shipped, reviewed, and tested feature via orchestrator → architect → developer → PR reviewer → QA → Playwright.

## Components

### Agents

- **architect**: See `agents/architect.md`
- **implement**: See `agents/implement.md`
- **orchestrate**: See `agents/orchestrate.md`
- **playwright**: See `agents/playwright.md`
- **qa**: See `agents/qa.md`
- **review**: See `agents/review.md`

### Commands

- **/ship-mate:setup**: See `commands/setup.md`
- **/ship-mate:ship**: See `commands/ship.md`

### Skills

- **scan**: See `skills/scan/SKILL.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
