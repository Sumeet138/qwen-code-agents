# skill-forge-essentials

Three behavioral skills addressing AI-specific failure patterns: hidden code debt from agent generation, context compaction amnesia, and imprecise Design Mode edits

## Components

### Skills

- **ai-debt-detector**: See `skills/ai-debt-detector/SKILL.md`
- **session-guard**: See `skills/session-guard/SKILL.md`
- **visual-edit-precision**: See `skills/visual-edit-precision/SKILL.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
